## CRM Operational Visibility Permissions

CRM users may need visibility into selected LMS operational data for planning, admissions, and trainer allocation.

### Admin / Operations
Can view:

- Active / running batches
- Batch capacity
- Assigned trainers
- Upcoming classes
- Trainer workload
- Trainer availability
- Class timings in the source US timezone
- Corresponding India IST time

### Sales
May view:

- Active batches
- Available batch capacity
- Trainer availability
- Upcoming class schedules

This helps the sales team place a newly admitted student into a suitable batch without accessing academic records that are not required for sales.

### Management
May view:

- Total active batches
- Total active trainers
- Upcoming classes
- Trainer workload summaries
- Capacity/utilization summaries

### Finance
Finance access to LMS operational data should be limited to what is required for payment/admission operations. Finance should not automatically receive academic progress or trainer-management permissions.

### Read-Only Principle

CRM visibility of LMS schedules should be read-only by default.

Changes to:

- Batch schedules
- Trainer assignments
- Class days
- Class times
- Student-to-batch assignments

should be made in the LMS unless an approved cross-system workflow is implemented later.
